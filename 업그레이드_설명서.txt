당뇨병 치료제 AI 정보분석실 v3 — GitHub Desktop 업데이트 가이드
기준: 2026-10-30
저장소: mysticlab1/diabetes-pharma-lab

[먼저 읽기]
이 ZIP은 '이미 설치된 v2'를 위한 교체 파일만 포함합니다.
기존 data/ 폴더(68건 저장 기록)나 site/ 폴더를 삭제하지 않습니다.
압축파일 자체를 GitHub에 업로드하지 않고, 압축을 푼 내부 파일을 복사합니다.

[쉬운 설치 순서]
1. GitHub Desktop 실행 → 현재 저장소 diabetes-pharma-lab 선택.
2. 상단 Repository → Show in Explorer 클릭.
3. 다운로드한 v3_업데이트_덮어쓰기용.zip 압축 해제.
4. 압축 해제한 폴더 내부의 파일과 .github, tests 폴더를 모두 선택·복사.
5. 2번에서 연 저장소 폴더에 붙여넣기. '같은 이름의 파일을 바꾸시겠습니까?' → 바꾸기.
   중요: data 폴더나 site 폴더는 건드리지 말 것! (업데이트 ZIP에도 포함되지 않음)
6. GitHub Desktop의 Changes 항목에서 변경된 파일이 보이는지 확인.
7. Summary 칸: 'Upgrade diabetes pharma dashboard to v3' 입력.
8. Commit to main 클릭.
9. Push origin 클릭. (현재는 Publish repository를 다시 누르는 게 아님.)
10. GitHub 웹사이트 Actions에서 'Daily diabetes drug research update'의 새 실행 확인.
    config.json이나 코드 변경이 main에 올라가면 자동 실행될 수 있음.
11. 녹색 체크 후 기존 웹사이트 새로고침: https://mysticlab1.github.io/diabetes-pharma-lab/

[추가된 기능]
- 지난번 수집/최근 수집 구분 및 최근 7일 날짜 필터.
- 미래에 지정된 논문 서지 날짜를 '미래 서지 날짜'로 표시.
- '우선 확인할 자료'에 변경 기록/최근 수집 중심으로 후보 제시(임상 안전성 중요도 아님).
- PubMed의 일부 초록을 가져와 AI가 검토하는 선택 기능. (OpenAI API 키 필수)
- 국내 데이터 조회 연결 준비: 식약처 품목허가 목록 일부/심평원 성분분류 일부.
  둘 다 data.go.kr 승인 API 키 필요. 현재 키가 없다면 국내 자료는 수집하지 않음.

[국내 자료 연결은 아직 선택 사항]
1. https://www.data.go.kr/ 에 가입하고 아래 2개 API 각각 활용신청:
   - '식품의약품안전처_의약품 제품 허가정보' (15095677)
   - '건강보험심사평가원_의약품성분약효정보조회서비스' (15021027)
2. 발급된 디코딩 인증키를 GitHub 저장소 Settings → Secrets and variables → Actions
   → New repository secret에 이름 'DATA_GO_KR_API_KEY'로 입력하고 저장.
3. GitHub Actions에서 수동 실행. 로그/웹사이트 '자료원 실행 상태'로 응답 확인.
중요: 국내 API는 연결 및 실제 호출 검증 전이며 API 항목 명세가 변경될 수 있어 코드 보정이 필요할 수 있음.
이 시범 API는 안전성 서한, 허가사항 변경대비표, 급여기준 개정을 감시하지 않음.

[AI 논문 분석을 사용하려면]
- GitHub 저장소 Settings → Secrets and variables → Actions
  → New repository secret: OPENAI_API_KEY = 본인이 발급받은 API 키
- 선택사항: Variables에 OPENAI_MODEL 지정. 모델 기본값은 gpt-4.1-mini.
- ChatGPT 구독과 API 비용은 별개로 청구됨.
- API 키는 절대 공개 저장소의 코드·README·config.json에 직접 붙여넣지 말 것.
- 키가 없으면 사이트는 정상 갱신하되 AI 분석 페이지는 생성하지 않음.
- AI 검토는 일부 PubMed 초록 기반의 검증 전 초안이며 환자 치료 판단에 사용하지 않음.

[현재 사용 범위 및 한계]
- 무료 공개 사이트이며 모든 사람이 접근할 수 있음.
- PubMed/ClinicalTrials.gov/openFDA 자료 수집은 이전 버전과 동일한 공식 API 기반.
- 국내 품목/성분 일부 조회가 성공하더라도 국내 허가·급여·안전성의 포괄적 자동 감시가 아님.
- 최초 자료 등록과 자료 자체의 발표일은 다름.
- 매일 오전 7:17 KST 실행 예정 (GitHub 실행 지연/비활성화 가능).
- 초록/서지정보에는 저작권, 데이터 이용조건이 있으므로 전문을 복제·판매하지 않음.
- 중요한 치료/보험/안전성 관련 결정은 식약처·심평원 원문 및 전문 검증 필요.
